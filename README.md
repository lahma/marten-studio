# Marten Studio

An embeddable Blazor Server admin UI for [MartenDB](https://martendb.io), shipped as one NuGet Razor Class
Library. Register it with `AddMartenStudio()` and mount it with `MapMartenStudio()` inside your own
ASP.NET Core application; it runs against that application's own configured `IDocumentStore`.

Work in progress — not yet released.
