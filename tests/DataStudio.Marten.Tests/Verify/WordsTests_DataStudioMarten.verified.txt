[PartitionedIndexRepair]

[PlanIndexRemedy]
An index whose leading column the filter compares lets Postgres read only the rows it keeps. For a document table, declare it in the store's options - a computed index, or a duplicated field - because an index made by hand on a Marten table is dropped by the next CreateOrUpdate; the Query page's index advisor writes the line for a where clause. For any other table, add it in your own migrations, built CONCURRENTLY on a table in use.

[PlanPatternRemedy]
A btree index can serve a pattern only by the fixed text it starts with, so one that starts with % or _ tests every row. A trigram index (the pg_trgm extension's GIN index, gin_trgm_ops) serves it - for a document table declared in the store's options, because an index made by hand on a Marten table is dropped by the next CreateOrUpdate - and so does searching for a prefix instead, or full-text search.
